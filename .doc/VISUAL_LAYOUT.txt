2. Uploads a .sav or .json vault file
3. File is parsed and loaded into state
4. Shows "Common Editor" view by default
5. User clicks "VAULT MODE" (home icon button)

7. RoomViewer renders the grid:
   - Calculates grid bounds
   - Builds position map
   - Renders all rooms with proper sizing
8. User can:
   - Hover over rooms for details
   - View all room types in legend
   - See power/broken status warnings
   - Navigate with scroll on small screens
